# Python Reference

Esta pasta é uma referência prática de Python.

Cada arquivo reúne exemplos executáveis de um grupo de conceitos.
A ideia não é resolver exercícios específicos, mas manter uma coleção
de sintaxe, padrões e operações para consulta.

## Arquivos

- `01_Python_Basics.py` — fundamentos da linguagem
- `02_Python_Collections.py` — list, tuple, set e dictionary
- `03_Python_Functions.py` — funções e argumentos
- `04_Python_OOP.py` — orientação a objetos
- `05_Python_Exceptions.py` — exceções e tratamento de erros
- `06_Python_Files_IO.py` — arquivos e streams
- `07_Python_Modules.py` — módulos, imports e biblioteca padrão
- `08_Python_Types.py` — type hints e tipagem
- `09_Python_Advanced.py` — iteradores, generators, decorators e context managers
- `10_Python_Data_Processing.py` — JSON, CSV, strings e regex

## Observação

Alguns exemplos criam arquivos (`output.txt`, `player.json`, `players.csv`)
ou diretórios durante a execução. Isso é intencional: a pasta funciona como
um pequeno laboratório de Python.
